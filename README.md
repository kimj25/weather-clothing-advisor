# Weather Clothing Advisor 🌦️👔

**[🌐 CLICK HERE FOR VIEW LIVE DEMO](https://weather-clothing-advisor.netlify.app/)**

**Features:**

Temperature Input - Fahrenheit and Celsius support
Weather Conditions - Sunny, rainy, cloudy, windy, humid
Activity-Based - Work, casual, exercise, or outdoor adventure
Smart Recommendations - Combines weather + activity for practical advice
Responsive Design - Works on desktop and mobile

**Built With**

React
JavaScript (ES6+)
Tailwind CSS
Lucide React (icons)

** UPCOMING **
Weather API integration for real-time data
Save favorite combinations
AI-powered personalized recommendations
